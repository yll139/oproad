# VS Code Usage

This repository includes VS Code tasks that call the host-side `oproad` wrapper.
The Docker container is still only the toolchain runtime.

Open the repository folder in VS Code, then run:

```text
Terminal -> Run Task...
```

Available tasks:

- `oproad: build Docker image`
- `oproad: new project`
- `oproad: simulate`
- `oproad: synthesize`
- `oproad: report`
- `oproad: implement`
- `oproad: clean project`
- `oproad: delete project`
- `oproad: open container shell`

The `new project` task asks for platform, design name, and target frequency.
All other project tasks ask only for the project directory because the platform
is stored in `.asic_project`.

All VS Code tasks call the host-side `oproad` script. The script bind-mounts the
local project directory into the Docker container, so edits made in VS Code and
files generated by OpenROAD/Yosys in the container are synchronized immediately.

Use the `oproad: delete project` task to remove projects. Do not delete project
folders manually from VS Code, because the task also runs the container-side
cleanup for matching ORFS working copies, logs, reports, results, and objects.
